# Java Selection Process

A Java selection process simulation developed as part of a **DIO Bootcamp challenge**.

## About

This project simulates a candidate selection process based on salary expectations and includes a simple mechanism for attempting to contact selected candidates.

The project demonstrates basic Java programming concepts such as:

* Conditional statements
* Loops
* Arrays
* Methods
* Random number generation

## Technologies

* Java

## Project Status

This project was completed as part of a **DIO Bootcamp challenge** and is no longer under active development.
